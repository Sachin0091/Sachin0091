## 🔐 Cybersecurity Mini-Projects

Hands-on security tools built to practice core concepts — networking, cryptography, auth, and threat detection. Each repo includes a working CLI, README, and (where relevant) safety/usage notes.

| Project | Description |
|---|---|
| [network-port-scanner](https://github.com/Sachin0091/network-port-scanner) | Multi-threaded TCP port scanner for auditing your own hosts/network |
| [ip-address-info-finder](https://github.com/Sachin0091/ip-address-info-finder) | Looks up geolocation & network info (ISP, ASN, timezone) for an IP address |
| [url-safety-checker](https://github.com/Sachin0091/url-safety-checker) | Heuristically rates a URL's phishing/scam risk, with optional live TLS check |
| [phishing-website-detector](https://github.com/Sachin0091/phishing-website-detector) | Scans a webpage's content for phishing indicators (fake login forms, brand impersonation) |
| [login-authentication-system](https://github.com/Sachin0091/login-authentication-system) | Login system demonstrating salted PBKDF2 password hashing and brute-force lockout |
| [file-encryption-decryption-tool](https://github.com/Sachin0091/file-encryption-decryption-tool) | Encrypts/decrypts files using Fernet (AES) with passphrase-based key derivation |
| [caesar-cipher-text-encryptor](https://github.com/Sachin0091/caesar-cipher-text-encryptor) | Caesar cipher tool with encrypt, decrypt, and frequency-analysis brute-force crack modes |
| [password-strength-checker](https://github.com/Sachin0091/password-strength-checker) | Scores password strength and gives actionable feedback |
| [password-generator](https://github.com/Sachin0091/password-generator) | Generates cryptographically secure random passwords |

*More in progress: file integrity checker, keylogger detection, signature-based malware scanner, packet sniffer, Wi-Fi scanner, DNS lookup, website security scanner, and system log analyzer.*
